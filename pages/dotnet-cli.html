Narzędzia .NET (PRG1)

Tworzenie, budowanie i uruchamianie aplikacji w technologii .NET.

Nawigacja

  • Strona główna
  • Terminal Bash (UKOS)
  • Git i GitHub (WARP)

Tabela poleceń CLI

Podstawowe polecenia .NET
Polecenie Opis
dotnet --version Sprawdza zainstalowaną wersję pakietu .NET SDK.
dotnet --list-sdks Wyświetla wszystkie zainstalowane w systemie wersje SDK.
dotnet new list Wyświetla listę dostępnych szablonów projektów.
dotnet new console Tworzy nowy projekt aplikacji konsolowej w bieżącym katalogu.
dotnet restore Przywraca zależności i pakiety NuGet wymagane przez projekt.
dotnet build Kompiluje projekt i jego zależności.
dotnet run Kompiluje (jeśli to konieczne) i uruchamia aplikację.
dotnet clean Czyści pliki wyjściowe poprzedniej kompilacji (katalogi bin i obj).

Kompletna sekwencja startowa

Oto jak od zera utworzyć i uruchomić nową aplikację konsolową:

mkdir MojaAplikacja
cd MojaAplikacja
dotnet new console
dotnet run
