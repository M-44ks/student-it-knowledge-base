Terminal Bash (UKOS)

Podstawowe polecenia i zasady pracy w terminalu Linux/Unix.

Nawigacja

  • Strona główna
  • Git i GitHub (WARP)
  • Narzędzia .NET (PRG1)

Zasady bezpiecznej pracy

  • Zawsze sprawdzaj, w jakim katalogu się znajdujesz (pwd), zanim cokolwiek usuniesz.
  • Używaj klawisza Tab do automatycznego uzupełniania ścieżek i nazw plików.
  • Pamiętaj o wielkości liter! Plik Dane.txt to nie to samo co dane.txt.

Polecenie rm usuwa pliki bez użycia kosza. Przed wykonaniem sprawdź bieżący katalog.

Tabela poleceń

Podstawowe polecenia Bash
Polecenie Przykład Opis
pwd pwd Wyświetla pełną ścieżkę obecnego katalogu roboczego.
ls ls -l Wypisuje zawartość katalogu (pliki i podkatalogi).
cd cd nazwa_katalogu/ Zmienia bieżący katalog roboczy.
mkdir mkdir nowy_folder Tworzy nowy, pusty katalog.
touch touch plik.txt Tworzy nowy pusty plik lub aktualizuje czas jego modyfikacji.
cp cp plik.txt kopia.txt Kopiuje pliki (aby skopiować katalog użyj flagi -r).
mv mv stary.txt nowy.txt Przenosi pliki/katalogi lub zmienia ich nazwę.
rm rm plik.txt Trwale usuwa pliki (aby usunąć katalog użyj flagi -r).
cat cat plik.txt Wyświetla całą zawartość pliku tekstowego w terminalu.
clear clear Czyści ekran terminala.
